How Smart Match works

Three easy steps take you from a skill list to a shortlist of jobs that actually fit.

  1. 01

    Create your profile

    Add your skills, experience, preferred category and availability. Everything stays in your browser.

  2. 02

    Let Smart Match score jobs

    Our simple algorithm compares your skills with each job's required skills and calculates a match percentage.

  3. 03

    Apply to your best fits

    Review your ranked recommendations, see which skills matched, and apply to the strongest opportunities.

    How your score is calculated

    Smart Match compares each job's required skills with the skills in your profile.

    • Skills are compared without case sensitivity.
    • Score = matched skills ÷ required skills.
    • Recommendations are re-ranked every time you save.

    About the project

    Built as a college demo

    SkillBridge shows how a simple recommendation idea can become a useful, interactive web experience.

    Project objective

    To help freelancers quickly find relevant work by showing a transparent skill-match score instead of an endless list of unrelated jobs.

    The recommendation is a readable JavaScript algorithm, not a black box — every matched and missing skill is shown.

    Technology used

    • HTML5 semantic structure
    • CSS3 Grid, Flexbox & variables
    • Vanilla JavaScript (ES6+)
    • JSON parsing & localStorage
    • No frameworks or build tools
